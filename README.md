# DroneStrike

משחק דפדפן בעברית: אתם מפעילי רחפן. תוקפים יעדים, מחפים על כוחות קרקעיים, מחלצים חטופים ועוקבים אחרי רכבים חשודים.
אחרי כל משימה מרוויחים כסף, וקונים רחפנים, תחמושת, חיישנים ומיגון.

- עובד בטלפון (מגע וצביטה לזום) ובמחשב (עכבר ומקלדת), ואפשר להתקין אותו כאפליקציה.
- קובץ אחד (`index.html`), בלי התקנות.

## הרצה
```
python3 -m http.server
```
ולפתוח את `http://localhost:8000/`.
